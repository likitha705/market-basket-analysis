🛒 Market Basket Analysis at Scale
Frequent Pattern and Association Rule Mining via Graph-based Entity Resolution and Data Deduplication — Applied to Retail Supermarket Chain Analytics

📌 Project Abstract
Retail supermarkets generate large volumes of transactional data every day. This project builds a complete, interactive web application that combines:

Graph-based Entity Resolution — identify and group duplicate/variant product names using RapidFuzz + NetworkX
Data Deduplication — map variant product records to canonical identities
Frequent Pattern Mining — discover frequent itemsets using Apriori or FP-Growth (mlxtend)
Association Rule Mining — generate and rank rules by Support, Confidence, and Lift
Interactive Visualisations — PyVis network graphs, Plotly charts, sortable tables
Business Insights — data-driven recommendations for shelf placement, bundles, and cross-selling

⚙️ Local Setup & Installation

bash

🚀 Quickstart Workflow
Open the app in your browser.
Navigate to 📂 Dataset Upload in the sidebar.
Click "Load Sample Dataset Directly" (or upload your own CSV).
Go to 🧹 Data Cleaning & Deduplication → click "Run Data Cleaning".
Set the similarity threshold and click "Detect Duplicate Products".
Click "Apply Deduplication" to confirm.
Go to 📊 Frequent Itemsets → select algorithm, set min support, click "Mine".
Go to 📋 Association Rules → set thresholds, click "Generate Rules".
Explore 🔗 Product Similarity Graph and 🌐 Co-purchase Graph for visual insights.
Visit 💡 Insights & Recommendations for business suggestions.
Download results from ⬇️ Download Results.
📋 Dataset Format
Your CSV file must have at least these two columns:

Column	Required	Description
transaction_id	✅ Yes	Unique identifier for each transaction
product_name	✅ Yes	Name of the purchased product
product_id	Optional	Product SKU or ID
quantity	Optional	Number of units purchased
category	Optional	Product category (Dairy, Fruits, etc.)
Column Mapping: If your CSV uses different column names, the app provides an interactive mapping interface on the upload page.

🔧 Troubleshooting
❌ ModuleNotFoundError: No module named 'mlxtend'
bash

pip install mlxtend
❌ ModuleNotFoundError: No module named 'pyvis'
bash

pip install pyvis
❌ ModuleNotFoundError: No module named 'rapidfuzz'
bash

pip install rapidfuzz
⚠️ No frequent itemsets found
Lower the Minimum Support slider (try 0.02–0.05).
Ensure your dataset has enough transactions with repeated item combinations.
Use the provided sample CSV to verify the pipeline works.
⚠️ No association rules generated
Lower Minimum Confidence (try 0.2) and Minimum Lift (try 0.8).
First ensure frequent itemsets were found.
⚠️ Graph not rendering / blank
Ensure pyvis is installed.
If running on Streamlit Cloud, the components.html() approach is used — check that your browser allows iframe content.
A Plotly fallback is provided automatically if PyVis is unavailable.
❌ Missing required columns error
Use the Column Mapping interface on the upload page to map your CSV columns.
Ensure your CSV has at least transaction_id and product_name.

📖 Key Concepts
Term	Definition
Support	P(A ∪ B) — fraction of transactions containing both A and B
Confidence	P(B|A) — of transactions with A, how many also contain B
Lift	Confidence / P(B) — values > 1 indicate positive association
Entity Resolution	Identifying records that refer to the same real-world entity
FP-Growth	Efficient frequent pattern mining using a compressed prefix tree
Apriori	Candidate-based frequent itemset mining algorithm
